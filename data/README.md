# Data

Nothing in this directory is redistributed. Two kinds of data are involved.

## 1. Public physiological corpora (pre-training)

Download these yourself and unpack them under `data/raw/<name>/`:

| Dataset | Contents (as the paper describes them) | DOI |
|---|---|---|
| MAMEM | 36 participants (18 able-bodied, 18 with motor impairments); EEG, GSR, heart rate, eye gaze with self-reported arousal/valence | [10.5281/zenodo.834154](https://doi.org/10.5281/zenodo.834154) |
| CLAS | 62 participants; ECG, PPG, EDA, accelerometry during arithmetic, logic and Stroop tasks | [10.1109/BIA48344.2019.8967457](https://doi.org/10.1109/BIA48344.2019.8967457) |
| WESAD | 15 subjects; chest-worn ECG, EDA, EMG, respiration, acceleration | [10.1145/3267305.3267350](https://doi.org/10.1145/3267305.3267350) |

Expected layout:

```
data/raw/
├── mamem/        # *.mat session files
├── clas/         # per-participant CSV blocks
└── wesad/
    ├── S2/S2.pkl
    ├── S3/S3.pkl
    └── ...
```

`scripts/pretrain_encoder.py` picks up whichever are present. **The loaders in
`src/mcga_lm/data/public_datasets.py` are UNVERIFIED** — they encode the
published file layouts but have not been run against the real archives here, and
the channel harmonisation is a placeholder (assumption A-27).

If none are present the script falls back to a clearly-labelled synthetic
substitute and says so in its output and in the checkpoint metadata. Pass
`--require-public-data` to make that a hard error instead.

## 2. Persona data (evaluation)

There is nothing to download. Every evaluation in this repository runs on
**synthetic personas generated at run time** from `src/mcga_lm/data/personas.py`.

The paper's own 20 personas were annotated by two certified SLPs and a clinical
neuropsychologist and are not published, so the personas here are a structural
stand-in with the same composition (10 ALS / 6 cerebral palsy / 4 brainstem
stroke) and roughly the same graph size. They describe no real person.

The AAC-Intent-Corpus (5,000 intent–utterance pairs sourced
from AAC user forums and SLP role-plays) is likewise unavailable; a synthetic
stand-in of the same shape is generated by `src/mcga_lm/data/corpus.py`. It
contains no real user language.

```bash
python scripts/make_personas.py --out runs/ --save-graphs
```

writes `runs/personas/` for inspection.
